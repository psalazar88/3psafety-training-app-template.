# Checklist: Mobile crane (periodic / annual)

Use for truck cranes, rough-terrain, all-terrain, crawler and boom trucks. The items follow the areas covered by OSHA 29 CFR 1926.1412 and ASME B30.5. Cite a specific paragraph only if its text is in the reference material; otherwise write "standard reference to be confirmed by inspector".

For every item: **OK (visible)**, **Possible defect**, or **Not visible in photos**.

## 1. Identification
- Manufacturer, model, serial number (nameplate)
- Unit / fleet number, hour meter, odometer
- Capacity chart present in cab and matches configuration
- Previous inspection sticker / date

## 2. Boom, jib and structure
- Boom sections: dents, bends, cracks, corrosion, weld cracks, paint cracking at welds (sign of cracks)
- Lattice booms: bent, missing or damaged lacing and chords
- Boom pins, keepers and retainers present and secured
- Jib / extension: stowage brackets, pins, attachment points
- Wear pads on telescopic sections
- Boom tip sheaves and head
- Turntable / slewing ring: cracks, loose or missing bolts
- Carrier frame and outrigger boxes: cracks, deformation

## 3. Wire rope and reeving
- Broken wires (count per lay if visible), kinks, birdcaging, crushing, core protrusion
- Corrosion, dry rope (no lubrication)
- Diameter loss (note "measure in field"; never estimate from photo)
- End connections: wedge socket, dead-end, clips correctly installed
- Proper reeving, rope seated in sheave grooves
- Drum spooling: crossover, gaps, minimum wraps

## 4. Sheaves and drums
- Groove wear, cracked or chipped flanges
- Bearings / guards present
- Drum: cracks, flange damage, rope guards

## 5. Hook block, hooks and overhaul ball
- Hook latch present and closes fully
- Hook: twist, cracks, gouges, throat opening (note "measure in field")
- Hook swivels / nut and keeper secured
- Block sheaves, guards, capacity and weight marking legible
- Overhaul ball: damage, weight marking

## 6. Outriggers / stabilizers / crawlers
- Beams and jacks: bends, cracks, hydraulic leaks
- Floats / pads present and undamaged; cribbing / mats if shown
- Pins and locks
- Crawler tracks, shoes, rollers, tension (crawler cranes)

## 7. Hydraulics
- Leaks at cylinders, hoses, fittings, pumps
- Hose condition: abrasion, bulges, cracking, improper routing
- Boom lift / telescope cylinders: rod scoring, pitting, leaks
- Hydraulic tank level / sight glass if visible

## 8. Cab, controls and safety devices
- Cab glass: cracks that impair view
- Controls labeled, levers return to neutral
- Load moment indicator (LMI / RCL) display present and powered
- Anti-two-block device and weight / switch present and connected
- Boom angle indicator, level indicator, length indicator
- Horn, lights, backup alarm (only if evidence is visible)
- Fire extinguisher present, charged gauge
- Seat belt, mirrors, steps and handholds

## 9. Carrier / drivetrain
- Tires: cuts, bulges, tread, mismatched sizes
- Wheels: cracks, missing lug nuts
- Fluid leaks under carrier
- Swing / house lock

## 10. Markings, guarding and housekeeping
- Capacity charts, warning decals, hand-signal chart legible
- Guards on gears, belts, rotating parts present
- Counterweight secured, correct for configuration if marked
- Walkways clear, no loose items on deck

## 11. Modifications
- Any welding, added brackets, altered components
- Manufacturer or qualified-engineer approval documented? (If unknown: "approval documentation not provided - verify")
